# 차곡 (Chagok) 1.10

압축 / 분할 압축 / 압축 해제만 하는 Windows용 경량 압축 프로그램.
C++ + Win32 API + GDI/GDI+ (UI 전부 직접 그림), 압축 알고리즘은 miniz(deflate) 사용.

- 설치 파일: `ChagokSetup-1.6.0.exe` (약 1MB, Windows 10/11 x64)
- 설치 없이 `Chagok.exe`만 복사해서 써도 ZIP은 됩니다. 다른 형식은 같은 폴더에 `7z.dll`이 있어야 합니다.
- 실행하면 탐색기 화면에 압축 파일 내용을 표시

## 설치

`ChagokSetup-1.6.0.exe`를 실행 → 다음 → 설치.

- 관리자 권한(UAC) 없이 현재 사용자에게 설치됩니다: `%LOCALAPPDATA%\Programs\Chagok`
- 구성 요소: 차곡 프로그램(필수), 탐색기 우클릭 메뉴 등록(기본 선택), 바탕 화면 바로 가기(선택)
- 시작 메뉴에 "차곡"이 생기고, 설정 → 앱 → 설치된 앱에서 제거할 수 있습니다.
- 차곡이 실행 중이면 설치·제거 전에 종료하도록 안내합니다.
- 다시 설치하면 덮어쓰기(업데이트)됩니다.
- 제거하면 프로그램 파일, 시작 메뉴·바탕 화면 바로 가기, 우클릭 메뉴, 저장된 설정이 모두 지워집니다.
- 무인 설치/제거(배포용): `ChagokSetup-1.6.0.exe /S`, `"%LOCALAPPDATA%\Programs\Chagok\uninstall.exe" /S`
- 서명이 없어서 처음 실행할 때 SmartScreen이 "Windows의 PC 보호" 창을 띄울 수 있습니다 → **추가 정보 → 실행**.

## ZIP 기본 프로그램으로 설정

설치하면 차곡이 ZIP(.zip/.z01/.001)의 **연결 프로그램 후보**와 Windows **기본 앱 목록**에 등록됩니다.
Windows 10/11은 보안상 프로그램이 스스로 기본 앱이 될 수 없어서, 마지막 선택은 사용자가 합니다.

- 설치 마지막 화면의 **ZIP 기본 프로그램으로 설정** 체크, 또는 차곡 ◐ 메뉴 → **ZIP 기본 프로그램으로 설정…** → 설정 열기
  - Windows 11: 차곡 화면에서 `.zip` 옆 프로그램을 눌러 **차곡** 선택 → 기본값 설정
  - Windows 10: 파일 형식별 기본 앱 선택 → `.zip` → **차곡**
- 또는 ZIP 우클릭 → 연결 프로그램 → 다른 앱 선택 → **차곡** → **항상**
- 설정 후 ZIP 파일을 더블클릭하면 차곡으로 열리고 아이콘도 차곡 아이콘으로 바뀝니다.
- 제거하면 등록도 함께 지워지고 Windows가 이전 기본 앱(탐색기)으로 돌아갑니다.
- 명령줄: `Chagok.exe /register-assoc`, `/unregister-assoc`, `/default-apps`(등록 + 설정 창 열기)

## 지원 형식

두 가지 방식(모드)으로 나눠 처리합니다.

- **ZIP 계열**: 차곡 자체 엔진(멀티코어)으로 처리하며 속도는 그대로입니다. 7z.dll을 불러오지도 않습니다.
- **그 밖의 형식**: 7-Zip 엔진(`7z.dll`)으로 처리하며, 해당 파일을 열 때만 불러옵니다.

| 구분 | 형식 | 열기·풀기 | 새로 만들기 | 파일 추가 |
|---|---|---|---|---|
| ZIP 계열 (자체 엔진) | zip, 분할 zip(.z01), zip.001, jar, war, ear, apk, xpi, ipa, aab | ○ | ○ (zip, 분할 가능) | ○ |
| 7z | 7z, 분할 7z(.7z.001) | ○ (암호 포함) | ○ (분할 가능) | ○ |
| tar 계열 | tar / tar.gz·tgz / tar.bz2·tbz / tar.xz·txz / tar.zst / tar.Z | ○ | tar, tar.gz (분할 가능) | tar만 |
| 단일 파일 압축 | gz, bz2, xz, lzma, zst, z | ○ | – | – |
| RAR | rar, 다중 볼륨(.part1.rar) | ○ (암호 포함) | – (RAR 압축은 독점 기술이라 만들 수 없음) | – |
| 디스크 이미지 | iso, img, vhd, vhdx, vmdk, dmg, wim | ○ | – | – |
| 기타 | cab, lzh·lha, arj, cpio, rpm, deb, xar, squashfs | ○ | – | – |

- 압축할 때 저장 창의 **파일 형식**에서 ZIP / 7z / TAR.GZ / TAR를 고릅니다. 마지막에 고른 형식을 기억합니다.
  - 분할 압축 결과는 ZIP이면 `.z01 … .zip`, 나머지는 `.001, .002 …`입니다.
- **tar.gz**: tar로 묶은 뒤 차곡 자체 엔진으로 gzip 압축합니다. ZIP과 같은 deflate 알고리즘이고 멀티코어로 동작합니다.
- **암호**:
  - 7z·rar는 암호가 걸려 있으면 입력 창이 뜹니다. 파일 목록까지 암호화된 7z도 열 수 있습니다.
  - 틀리면 다시 묻습니다(최대 3번).
  - ZIP 암호는 아직 지원하지 않습니다.
- **읽기 전용 형식**(rar, iso, tar.gz 등)은 "파일 추가" 버튼이 꺼지고, 끌어다 놓으면 새로 압축할지 묻습니다.
- 7z·rar·tar.gz·iso를 하나만 골라 우클릭하면 ZIP과 같이 풀기 위주 메뉴가 나옵니다. 연결 프로그램 후보 목록에도 함께 등록됩니다.

형식별 압축 시간 (2코어, 위 640MB 자료, 수준 '보통'):

| 형식 | 시간 | 크기 |
|---|---|---|
| ZIP | 5.0초 | 432.6MB |
| TAR.GZ | 13.1초 | 432.6MB (gzip은 이미 압축된 파일도 다시 압축) |
| TAR | 0.9초 | 670.5MB (압축 없음) |
| 7z | 161초 (빠름 25.5초) | 424.2MB |

7z는 크기를 줄이는 대신 느린 형식입니다. 빠르게 압축할 때는 ZIP을 권장합니다.

## 기능

| 기능 | 사용법 |
|---|---|
| 압축 | `새로 압축`(B) / `압축`(C) → 파일 선택 또는 폴더 선택 → 저장 위치 |
| 분할 압축 | `분할 압축` → 분할 크기(10MB·100MB·700MB·1GB·4GB·직접 입력) → 파일/폴더 선택. 결과: `이름.z01, 이름.z02 … 이름.zip` |
| 압축 해제 | `압축 해제` → 위치 선택. 최상위 항목이 여러 개면 `압축파일이름` 폴더를 만들어 풂 |
| 파일 추가 | `파일 추가` → 현재 보고 있는 폴더에 추가. 같은 이름은 교체. 분할 압축 파일이면 같은 크기로 다시 분할 |
| 선택 항목 추출 | 목록에서 파일·폴더 선택(Ctrl/Shift 다중 선택 가능) → `선택 항목 추출` |

그 밖의 조작:

- 끌어다 놓기: 압축 파일을 놓으면 열고, 일반 파일·폴더를 놓으면 압축하며, 압축 파일이 열려 있을 때 놓으면 추가합니다.
- 키보드: ↑↓ / Enter(폴더 열기) / Backspace(상위 폴더) / Ctrl+A / Ctrl+O
- `Chagok.exe 파일.zip` 처럼 실행하면 바로 엽니다. .zip 연결 프로그램으로 지정해 두면 더블클릭으로 열 수 있습니다.

## Windows 11 우클릭 첫 화면 메뉴 (사내 인증서)

Windows 11 에서는 설치할 때 '차곡'을 우클릭 첫 화면에 바로 넣습니다. ('추가 옵션 표시'를 누를 필요 없음)

**설치할 때 일어나는 일**

1. 사내 인증서(`CN=Sinsul Chagok`)를 PC의 '신뢰할 수 있는 사용자' 저장소에 등록합니다. 이 단계만 관리자 확인 창이 한 번 뜹니다. 이미 등록된 PC는 건너뜁니다.
2. 같은 인증서로 서명한 스파스 패키지 `ChagokShell.msix`(약 25KB)를 등록합니다. 이 패키지는 설치 폴더의 `ChagokShell.dll`을 Windows 11 메뉴(IExplorerCommand)로 연결합니다.
3. 새 메뉴가 등록되면 예전 방식 메뉴는 지웁니다. 새 메뉴가 '추가 옵션 표시' 안에도 함께 나오므로 중복을 막기 위해서입니다.

**자동 대체:** 다음 경우에는 예전 방식 메뉴('추가 옵션 표시' 안)로 설치됩니다.

- Windows 10
- 관리자 확인에서 '아니요'를 누른 경우
- 패키지 등록에 실패한 경우

**제거:** 패키지를 해제하고, 설치 때 등록한 인증서도 지웁니다. 이때 관리자 확인 창이 한 번 뜹니다.

**메뉴 구성:** 선택한 항목에 따라 하위 메뉴가 바뀝니다.

- 압축 파일 하나: 현재 폴더에 압축 풀기 / "이름\"에 풀기 / 풀 위치 선택… / 차곡으로 열기
- 그 밖의 파일·폴더: 압축하기… / 분할 압축… / 차곡으로 열기

**인증서와 서명**

- `installer/cert/make_cert.sh`가 처음 한 번만 인증서를 만듭니다. RSA 3072, 유효기간 10년입니다.
- `chagok_sign.pfx`에는 **개인 키**가 들어 있습니다. 회사 안에서만 보관하고 외부에 공유하지 마세요. 기본 암호는 `chagok`이며, 빌드할 때 환경변수 `CHAGOK_PFX_PASS`로 바꿀 수 있습니다.
- 다음 버전도 같은 인증서로 서명해야 업데이트가 그대로 됩니다. 인증서를 새로 만들면 모든 PC에 다시 등록해야 합니다.
- 빌드할 때 `Chagok.exe`, `ChagokShell.dll`, 설치 프로그램에도 같은 인증서로 Authenticode 서명을 합니다.
- 회사 밖 PC에서는 이 인증서를 신뢰하지 않으므로 SmartScreen에 '알 수 없는 게시자'로 표시됩니다.
- 패키지 빌드는 Windows SDK 없이 `tools/mkmsix.py`(블록맵 생성)와 `osslsigncode`(서명)로 합니다.

## 탐색기 우클릭 메뉴 (서명 불필요)

설치하면 자동 등록됩니다. 직접 켜고 끌 때는 ◐ 메뉴 → **탐색기 › 우클릭 메뉴에 추가**를 누릅니다. 현재 사용자 영역(HKCU)에 등록하므로 관리자 권한이 필요 없습니다.

우클릭 메뉴에는 **차곡** 하나만 나오고, 선택한 내용에 따라 하위 항목이 바뀝니다. 메뉴 처리는 `ChagokShell.dll`이 맡습니다.

| 선택 | 차곡 ▸ |
|---|---|
| 압축 파일 하나 (.zip / .z01 / .zip.001) | 알아서 풀기 · 현재 폴더에 압축 풀기 · 파일 이름 폴더에 풀기 · 풀 위치 선택… · 알아서 풀고 압축 파일 지우기 · ─ · 차곡으로 열기 |
| 그 밖의 파일·폴더, 또는 여러 개 | **자료.zip 으로 압축** · (여러 개) **보고서.zip 으로 압축** · **자료_20261103.zip 으로 압축** · (여러 개) **각각 압축** · **암호 걸어 압축…** · ─ · 압축하기… · 분할 압축… · ─ · 차곡으로 열기 |

**바로 압축** (1.15) — 설정 창 없이 바로 만듭니다. 메뉴에 만들어질 파일 이름이 그대로 보입니다.
- 이름 규칙(`src/quickname.h`, 메뉴와 차곡이 함께 씀): 하나만 골랐으면 그 항목 이름(파일은 확장자 뺌), 여러 개면 들어 있는 폴더 이름. '보고서.zip 으로 압축'은 우클릭한 항목 이름
- 날짜 붙여 압축: `이름_YYYYMMDD`. 각각 압축: 고른 항목마다 따로(`A.zip`, `B.zip`…)
- 암호 걸어 압축: 암호 입력 창(암호·확인)만 뜨고 바로 압축 (AES-256)
- 형식은 설정의 프리셋을 따름(빠름 = ZIP, 보통·최대 = 7z). 같은 이름이 있으면 `자료 (2).zip`
- 끝나면 창 없이 종료. 설정 → 일반 → 우클릭 메뉴 '압축·풀기가 끝나면 탐색기에서 결과 보여 주기'(기본 켬)를 켜 두면 만든 파일을 선택해 보여 주고, 새 폴더에 풀었으면 그 폴더를 엶

**알아서 풀고 압축 파일 지우기** — 알아서 풀기와 같이 푼 뒤 압축 파일(분할이면 조각 전부)을 **휴지통**으로 옮깁니다. 풀지 못한 항목이 있거나 덮어쓰기 질문에서 건너뛰었거나 취소하면 지우지 않습니다.

- 압축 파일이 아닌 항목에서 **차곡으로 열기**를 누르면 차곡이 열리면서 압축 / 분할 압축 중 하나를 고르게 합니다. 끌어다 놓기와 같은 동작입니다.
- Windows 11에서는 우클릭 → **추가 옵션 표시**(또는 Shift+우클릭) 안에 나타납니다. 첫 화면 메뉴에 넣으려면 코드 서명이 필요합니다.
- 1.4 이하의 메뉴("차곡 압축"/"차곡 풀기" 두 개)는 1.5를 설치하거나 실행하면 자동으로 새 메뉴로 바뀝니다.
- 업데이트나 제거 때 탐색기가 DLL을 쓰고 있으면, 설치 프로그램이 그 DLL을 임시 폴더로 옮긴 뒤 진행합니다. 재부팅은 필요 없습니다.

명령줄 옵션 (배포 스크립트용):

```
Chagok.exe 파일.zip                 열기
Chagok.exe /compress 경로…          압축(저장 위치 선택)
Chagok.exe /split 경로…             분할 압축
Chagok.exe /x-here 파일.zip         여기에 풀기
Chagok.exe /x-folder 파일.zip       새 폴더에 풀기
Chagok.exe /x-to 파일.zip           풀 위치 선택
Chagok.exe /x-smart 파일.zip        알아서 풀기
Chagok.exe /x-del 파일.zip          알아서 풀고 압축 파일을 휴지통으로
Chagok.exe /c-folder 경로…          바로 압축 (폴더 이름)   /c-name (첫 항목 이름)  /c-date (날짜 붙임)
Chagok.exe /c-each 경로…            각각 압축               /c-pw (암호만 묻고 압축)
Chagok.exe /open 경로…              차곡으로 열기 (압축 파일이면 열기, 아니면 압축 방식 선택)
Chagok.exe /register | /unregister  우클릭 메뉴 등록/해제 (조용히)
  ※ 경로 대신 "@목록파일"(UTF-16, 한 줄에 한 경로)을 넘길 수 있습니다.
```

프로그램 이름은 `src/main.cpp`의 `APP_NAME` 한 곳만 바꾸면 창 제목과 우클릭 메뉴에 반영됩니다.

## 압축 속도

- **deflate 엔진 zlib-ng (1.16):** CPU 의 SIMD 명령을 쓰는 zlib 계열 엔진. 같은 결과 크기에서 miniz 보다 압축 CPU 시간 약 20~25%, 해제 CPU 시간 약 45~55% 적음. `build_mingw.sh` 가 zlib-ng 2.2.2 를 받아 정적 라이브러리로 넣는다(`src/zeng.cpp`). 자동 실행 파일 스텁과 MSVC 빌드는 miniz 그대로
- **작업 속도 설정 (1.16, 설정 → 프리셋):** **조용히**(기본) = 코어 절반(최대 4개) + 낮은 우선순위 — 다른 프로그램이 CPU 를 쓰면 차곡이 양보. **빠르게** = 모든 코어(최대 16개)
- **여러 코어 동시 사용:** 파일을 1MB 블록으로 나눠 정해진 코어 수만큼 동시에 압축합니다. 큰 파일 하나도, 작은 파일 여러 개도 모두 병렬로 처리합니다.
  - 압축 해제도 파일 여러 개를 동시에 풉니다.
- **이미 압축된 파일은 저장만:** jpg·png·mp4·mp3·zip·7z·docx·xlsx 같은 형식은 다시 압축해도 줄지 않아서 압축 과정을 건너뜁니다.
- **압축 프리셋(압축 설정 창):** 빠름(ZIP · Fast) / 보통(7z · HC4) / 최대(7z · LZMA2)
- **7z RAM 제한 (1.16):** 사전 크기를 보통 4MB · 최대 16MB 로, 최대는 코어 2개까지. 압축 RAM 보통 약 50MB(전 260~600MB) · 최대 약 200MB(전 0.5~1.7GB), 차곡이 만든 7z 를 풀 때 약 26MB / 75MB

측정값 (2코어 테스트 환경, 640MB: 텍스트 로그 160MB + 동영상·사진 400MB + 기타 80MB):

| | 압축 시간 | 결과 크기 |
|---|---|---|
| 1.4 이하 (단일 코어, 수준 6) | 32.9초 | 429.3MB |
| 1.5 빠름 | 3.3초 | 439.8MB |
| 1.5 보통 (기본) | 4.3초 | 432.6MB |
| 1.5 최대 | 13.2초 | 429.5MB |

## 압축 설정 창

압축을 시작하면(버튼, 끌어다 놓기, 우클릭 '압축하기…') 압축 설정 창이 먼저 뜹니다. 우클릭의 바로 압축 항목은 설정 창 없이 만듭니다.

- **일반:** 저장 위치와 파일 이름(확장자에 따라 ZIP / 7z / TAR / TAR.GZ 형식이 정해짐), 분할 압축 켜기와 조각 크기
- **프리셋:** 빠름 · 보통 · 최대 카드 중 하나를 고릅니다. 고른 프리셋은 다음에도 기본값이 됩니다.
  - 상세 옵션: 암호화(AES-256)를 켜고 암호를 두 번 입력합니다.
  - 창 투명도 슬라이더: 40~100%이며, 모든 차곡 창에 바로 적용됩니다.
- **보안 및 기타:** 우클릭 메뉴 등록, 기본 압축 프로그램 설정, 암호화 안내

## 진행 창

압축, 압축 해제, 파일 추가 중에는 진행 창이 뜨고 실제 측정값을 보여 줍니다.

- 진행률과 몇 번째 파일인지 (전체 N개 중 M개째)
- 속도: 최근 3초 평균
- 남은 시간과 처리한 양 (예: 640MB 중 416MB 처리됨)

**백그라운드로 작업**을 누르면 창이 숨고, 작업 표시줄 아이콘과 목록 아래 작은 진행 막대에 진행률이 표시됩니다. 그 막대를 누르면 진행 창이 다시 열립니다.

화면은 0.1초마다 작업 카운터를 읽기만 하므로 압축 속도에는 영향이 없습니다.

차곡을 켤 때 업데이트 위치를 뒤에서 확인하고, 새 버전이 있으면 업데이트할지 묻습니다 → '업데이트'를 누르면 내려받아 확인한 뒤
조용히 설치하고 차곡을 다시 엽니다(관리자 확인 없음, 몇 초). '나중에' / '이 버전 건너뛰기'도 고를 수 있고, 작업 중이면 끝난 뒤에 묻습니다.

**사내 위치** — 사내 공유 폴더(`\\파일서버\공유\차곡`) 또는 웹 주소(`https://intra.../chagok/`) 둘 다 됩니다.
- 설치할 때 넣기: `CHAGOK_UPDATE_URL='\\파일서버\공유\차곡' sh build_mingw.sh` 로 빌드한 설치 파일은 그 위치를 자동으로 씁니다.
- PC 별로 바꾸기: 설정 → 보안 및 기타 → 자동 업데이트 → '사내 위치…' (같은 곳에 '지금 확인', '시작할 때 새 버전 확인' 켜고 끄기)

**새 버전 올리기**
1. `res/*.rc`, `installer/chagok.nsi` 의 버전을 올리고, `installer/update-notes.txt` 에 바뀐 점을 적는다
2. `sh build_mingw.sh` → `build/update/` 에 `chagok-update.ini` 와 `ChagokSetup-x.y.z.exe` 가 생긴다
3. GitHub: 태그 `v<버전>` 으로 릴리즈를 만들고 두 파일을 첨부한다 (`gh release create v1.14.1 build/update/* --title "차곡 1.14.1" --notes-file installer/update-notes.txt`)
4. 사내 위치도 쓰면: 두 파일을 사내 위치에 복사한다 (설치 파일을 먼저, ini 를 나중에)

**안전 장치** — 받은 설치 파일의 SHA-256 이 ini 와 같고, 사내 인증서(지문 `CERT_THUMB`)로 서명된 경우에만 설치합니다.
공유 폴더에 누가 다른 파일을 넣어도 사내 서명 키(`chagok_sign.pfx`) 없이는 설치되지 않습니다.

**설치 프로그램 옵션** — `ChagokSetup.exe /S /UPDATE`: 질문 없이 설치, 인증서 등록(UAC)은 건너뜀(이미 신뢰된 경우에만 Windows 11 첫 화면 메뉴), 끝나면 `Chagok.exe /updated` 실행.

## 1.12.1 고친 점

- 압축을 풀 때 '같은 이름의 파일이 있습니다' 질문(그리고 암호 질문)이 진행 창 뒤로 숨던 문제. 진행 창은 0.25초 뒤에 뜨는데, 첫 파일에서 바로 물으면 늦게 뜬 진행 창이 질문을 덮었음 → 질문을 띄우기 전에 진행 창을 먼저 띄우고 그 창을 주인으로 삼아 항상 맨 앞에. 다른 프로그램을 쓰는 중이면 작업 표시줄에서 깜박임

- **내 PC 둘러보기 (탐색기)**: 처음 화면의 '내 PC 둘러보기', 또는 압축 파일 맨 위에서 뒤로(←/Backspace) 하면 그 압축 파일이 있는 폴더
  - 내 PC: 바탕 화면·문서·다운로드·사진 + 드라이브. 트리 배치 테마는 왼쪽에 같은 목록
  - 폴더 이동(두 번 누르기·경로 단추·뒤로), 이 폴더에서 찾기, 정렬(이름·크기·종류·날짜), 큰 아이콘
  - 압축 파일은 두 번 누르면 차곡에서 열림. 다른 파일은 연결된 프로그램으로
  - 항목을 골라 '새로 압축'/'분할 압축' → 바로 압축 설정 창. 끝나면 그 폴더에서 새 파일을 골라 보여 줌
  - 압축 파일을 골라 '압축 해제' 또는 우클릭 → 여기에 풀기 / 새 폴더에 풀기 / 위치 지정 (여러 개 한꺼번에)
  - 우클릭: 열기 · 미리보기 · 압축하기 · 분할 압축 · SHA-256 · Windows 탐색기에서 보기 · 경로 복사 · 새로 고침(F5)
  - 끌어서 탐색기로 복사, 폴더가 바뀌면(파일 생김·지움) 목록 저절로 갱신, USB 꽂으면 드라이브 목록 갱신

## 1.11.1 속도 개선

- **빠른 CRC-32 (`src/fastcrc.cpp`)**: CPU 의 PCLMULQDQ 명령으로 계산(없으면 slice-by-8 표). miniz 기본 CRC 보다 약 16배 빠름. ZIP 압축·해제·검사와 자동 실행 파일 모두 적용
- **엔진만 속도 우선 컴파일**: deflate·ZIP·암호·CRC 는 -O2, 화면 코드는 -Os 그대로. 자동 실행 파일 스텁은 크기 우선(LTO -Os) 유지
- **파일이 많을 때 '압축 안 되는 파일' 판단을 작업 스레드로**: 전에는 1MB 이하 파일마다 읽기 스레드가 표본 압축을 직접 해서 병목이었음
- 측정 1GB (텍스트·DB·동영상·사진 섞음, 압축률 약 48%), 3회 평균, 2코어 테스트 환경, 파일이 메모리에 올라온 상태:

| 자료 | 압축 (1.11.0 → 1.11.1) | 해제 (1.11.0 → 1.11.1) |
|---|---|---|
| 1GB 파일 1개 | 8.5초 → 5.8초 | 5.9초 → 2.8초 |
| 같은 내용 500KB × 2,000개 | 8.9초 → 6.6초 | 4.3초 → 2.7초 |

- 압축은 1.0부터 이미 여러 코어를 쓴다(파일을 1MB 블록으로 나눠 동시에 압축, 최대 16스레드). 해제도 파일 단위로 최대 8스레드
- 크기: Chagok.exe 약 +65KB, ChagokSFX.bin 약 +8KB

## 1.11 추가 기능

- **목록**: 검색(Ctrl+F, 하위 폴더까지), 열 머리글 클릭 정렬, 끌어서 꺼내기(탐색기로 드래그)
- **미리보기**: Space — 이미지·텍스트(UTF-8/UTF-16/CP949), 파일당 64MB까지
- **최근 연 파일**: 빈 화면에 목록 표시
- **압축 파일 안에서 이름 바꾸기(F2)·삭제(Del)**: ZIP·7z, 다시 압축하지 않고 복사만 함
- **압축 파일 검사**: 풀지 않고 CRC 확인
- **이름 글자 코드 바꾸기**: 깨진 파일명을 CP949·Shift-JIS 등으로 다시 읽기
- **SHA-256 확인**: 선택 파일 또는 압축 파일 자체, 클립보드의 해시와 자동 비교
- **분할 프리셋 '20 MB (메일 첨부)'**
- **작업 대기열**: 작업 중에 다른 작업을 걸면 순서대로 처리
- **완료 알림**: 창을 떠나 있거나 대기열이 있을 때 트레이 알림
- **자동 실행 압축 파일(.exe)**: 압축 설정 → 일반 → '자동 실행 파일로 만들기'. 받는 사람은 차곡 없이 실행해 풀 수 있음 (ZIP 고정, 분할 불가, 결과물 +약 260KB)

압축·해제 엔진 경로는 바뀌지 않았으므로 속도 차이는 없다.

## 프로그램 아이콘

설정 → 일반 → 프로그램 아이콘에서 세 가지 중 고릅니다. 세 아이콘 모두 지퍼가 들어가 있어 압축 프로그램임을 알 수 있습니다.

| 아이콘 | 모양 |
|---|---|
| 가지런한 더미 | 반듯하게 쌓은 서류 더미를 가운데 지퍼가 꿰어 잠금 |
| **갠 이불 (기본)** | 한 겹씩 갠 이불 더미를 세로 지퍼가 묶음 |
| 정리함 | 파일이 가지런히 꽂힌 상자의 윗선을 지퍼가 잠금 |

아이콘을 바꾸면 다음 위치에 바로 적용됩니다.

- 창과 작업 표시줄
- 우클릭 메뉴의 차곡 아이콘
- 시작 메뉴·바탕 화면 바로 가기
- 차곡에 연결된 압축 파일의 아이콘

탐색기에서 보이는 Chagok.exe 파일 자체의 아이콘은 Windows 규칙상 기본(갠 이불)으로 고정됩니다.

## 호환성 (검증 완료)

- 일반 ZIP을 만들면 Windows 탐색기, 7-Zip, Info-ZIP에서 열립니다.
- 분할 ZIP(.z01 … .zip, PKWARE 표준)을 만들면 7-Zip과 반디집에서 열립니다. Windows 탐색기는 분할 ZIP 자체를 지원하지 않습니다.
- 다음 파일을 읽을 수 있습니다:
  - Info-ZIP/WinZip 방식 분할(.z01)
  - 7-Zip 방식 분할(.zip.001)
  - ZIP64(4GB 이상 파일, 항목 6만 5천 개 이상)
  - 한글 파일명: UTF-8, CP949(탐색기에서 만든 ZIP)
- 지원하지 않는 것: 암호 ZIP, deflate 이외의 압축 방식(LZMA·BZIP2 등). 이런 항목은 오류 목록에 표시하고 나머지는 계속 풉니다.
